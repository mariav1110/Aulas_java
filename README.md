📚 Conteúdo

O repositório reúne exercícios e atividades desenvolvidos durante as aulas, com foco nos fundamentos da programação em Java.

* Lógica de programação
* Variáveis e tipos de dados
* Entrada e saída de dados
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Programação orientada a objetos
* Exercícios práticos

🎯 Objetivo

Praticar os fundamentos de Java e desenvolver minha lógica de programação por meio de exercícios e atividades acadêmicas.
